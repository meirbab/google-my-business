## Lessons learned

1. **The DataForSEO Maps search with just the title returned nothing** for "מאיר בבייב". Adding coordinates (`32.0117,34.7740,30`) found it instantly. Always include coordinates.

2. **Description was 85 chars** — the single biggest neglected SEO lever. Expanding to ~545 chars with all service names took 60 seconds and is probably the most impactful single edit.

3. **Medical spa preset services include Liposuction** — this is the SEO-critical addition for a clinic doing laser lipo. The preset matches Google's internal entity for "liposuction near me" searches.

4. **The "Duplicate" profile in Nes Ziona shares the same `fid`** as the Holon profile. Clicking it redirects to the main profile. Cannot remove via UI. Skipped.

5. **Friday hours edit dialog uses comboboxes**, not free-text time entry. 30-minute granularity. Each day has its own "Closes at" combobox; only Friday needed changing.

6. **Postcode field accepts pure digits only**. Hebrew/RTL doesn't apply to it.

7. **`type()` appended in the postcode field** instead of replacing. Used `fill()` to force replace.

8. **The Playwright session disconnects randomly** when the Google SERP iframe reloads after a save. Pattern: after each save, the dialog tab refs (`f5e*`) get re-numbered. Always re-snapshot after Save before clicking next button.

9. **Google auto-suggested 5+ attribute changes** while we were editing (wheelchair access additions, gender-neutral toilet flip, NFC payments). These appeared as diffs in the side panel. User should review and approve/reject separately.

10. **Browser process kills cleanly with `pkill -f "ms-playwright/mcp-chrome"`** when stuck. The SingletonLock symlink self-removes.
