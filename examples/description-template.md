# GBP Description templates

Hard 750-char limit. Aim for 500-700 chars (over 90% utilization) without keyword stuffing.

## Structure formula

1. **Lead with clinic/business name + city** (5-10% of budget) — anchors local entity
2. **Owner / credibility line** (10-15%) — years of experience, specialization
3. **Services list** (60-70%) — every search-worthy service, comma-separated, using customer-language terms
4. **Branded tech / equipment** (5-10%) — model names customers might search (eg `Quantum RF`, `Allergan Botox`)
5. **CTA** (5%) — phone number for booking

[SERVICE_3], [SERVICE_4], [SERVICE_5]. [INJECTION_TYPE] including [BRAND_1] and [BRAND_2]. Laser treatments for [CONDITION_1], [CONDITION_2], and [CONDITION_3]. [SERVICE_6], [SERVICE_7], and [SERVICE_8]. We use [TECH_BRAND_1] and [TECH_BRAND_2] technology. Call [PHONE] to book.

## Anti-patterns

❌ **Keyword stuffing**: "Best dermatologist near me skin care doctor laser hair removal Holon Tel Aviv liposuction Botox" — gets rejected on review

❌ **Vague claims**: "We're the best" / "Award-winning" without specifics

❌ **Future tense**: "We will offer..." / "Coming soon..." — Google flags as unestablished

❌ **Multiple phone numbers**: confuses Google's NAP signal

❌ **External links** in description: Google strips them and may flag

❌ **CAPS LOCK or excessive emojis**: gets visibility throttled

✅ **Do**: natural prose, services as a comma list, real branded tech names, single phone CTA at end

## Char counting tip (Hebrew)

Hebrew/Latin chars all count as 1. Punctuation, spaces, digits all count as 1. The textbox label "X of 750 characters entered" updates live — use it as your meter.

## Update frequency

GBP doesn't penalize description re-writes. Refresh when:
- New service added
- Address changes
- Branded tech upgraded (eg "Quantum RF" → "Quantum RF v2")
- Seasonal campaigns (eg add summer-specific phrasing in May)

Each save triggers a Google review (~24 hours), but the change is live within a few hours typically.
